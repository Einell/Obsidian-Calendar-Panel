# Calendar Panel

本插件在 [Calendar Panel](https://github.com/lizijing98/calendar-panel) 的基础上修改而成，原作者为 LL_Ricky。原项目地址：

<https://github.com/lizijing98/calendar-panel>

它在侧边栏提供一张月历，用来查看、打开和创建日记与周记。以下说明本版本相对原项目所作的调整，以及新增的待办功能。

## 日记与周记

新建日记、周记时，文件名会附上日期说明，便于在文件列表中辨认：

- 日记：`2026-09-29（周二）.md`
- 周记：`2026-W40（09-28 ~ 10-02）.md`

已按上述方式命名的笔记，日历可以照常对应到相应日期。

## 日历面板

在月历中点选某一天后，面板下方依次显示：

1. **创建日记**
2. **今日日记**
3. **今日笔记**
4. **今日截止**

「今日日记」列出当天的日记，「今日笔记」列出与这一天相关的其他笔记。「今日截止」列出应在这一天完成的待办。已经勾选的事项以删除线显示，已经过期的事项以淡色显示。

## 待办

待办写在笔记正文中，优先级在前，截止日期在后：

```markdown
- [ ] H end:2026-10-5 任务内容
```

三个字母分别表示重要程度，笔记中显示为对应颜色的圆点：

| 字母 | 重要程度 | 显示 |
| --- | --- | --- |
| H | 高 | 🔴 |
| M | 中 | 🟡 |
| L | 低 | 🔵 |

日期可以写成 `2026-10-5`，也可以写成 `2026-10-05`。编辑和阅读笔记时，字母会显示为圆点，正文中仍然保留 `H`、`M`、`L`。

日记末尾的「今日待办」也会被日历读取。写了 `end:` 的事项，记在截止日期那一天；没有写截止日期的事项，记在这篇日记所属的那一天。

### 在文中插入

在新的一行输入 `- [ ] `（方括号后留一个空格），即可出现下拉列表，共十一项：

- 🔴高优先级、🟡中优先级、🔵低优先级
- 从今天起连续七天的日期，例如「今天2026-9-29」「明天2026-9-30」
- 自定义

建议先选择优先级，再选择日期。选择优先级后插入 `H `、`M ` 或 `L `；选择日期后插入 `end:2026-10-5 `。若日期不在这七天之中，请选择「自定义」，在光标旁弹出的小日历中点选日期。优先级和日期都选定之后，下拉列表关闭，即可继续书写任务内容。

也可以不使用下拉列表，直接按上面的格式手写。

### 从侧边栏新建

左侧边栏提供「新建待办」按钮，命令面板中亦有同名命令。请先将光标置于要写入的笔记中，再点击该按钮，选择截止日期和优先级。插件会在光标处插入一条待办，例如：

```markdown
- [ ] H end:2026-10-5 
```

随后补上任务内容即可。

## 日历中的颜色

若某一天仍有未完成、且尚未过期的待办，这一天的日期数字会显示为该事项的优先级颜色。同一天有多项待办时，按红、黄、蓝依次取最高一级。

下列事项不改变日期颜色：

- 已经勾选完成的待办
- 截止日期早于今天的待办

将鼠标停留在日期上，可以看到这一天尚未完成的任务内容。
