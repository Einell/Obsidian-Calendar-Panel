# Calendar Panel

本插件在 [Calendar Panel](https://github.com/lizijing98/calendar-panel) 的基础上修改而成，原作者为 LL_Ricky。原项目地址：

<https://github.com/lizijing98/calendar-panel>

它在侧边栏提供一张月历，用来查看、打开和创建日记与周记。以下说明本版本相对原项目所作的调整。待办仍使用 Tasks 插件书写，日历按其截止日期与优先级标出对应日期。

## 日记与周记

新建日记、周记时，文件名会附上日期说明，便于在文件列表中辨认：

- 日记：`2026-09-29（周二）.md`
- 周记：`2026-W40（09-28 ~ 10-02）.md`

已按上述方式命名的笔记，日历可以照常对应到相应日期。

## 日历面板

在月历中点选某一天后，面板下方依次显示：

1. **创建日记**
2. **今日日记**
3. **今日笔记**
4. **今日截止**

「今日日记」列出当天的日记，「今日笔记」列出与这一天相关的其他笔记。「今日截止」列出应在这一天完成的待办。已经勾选的事项以删除线显示，已经过期的事项以淡色显示。

## 截止日期

日历读取笔记中由 Tasks 插件标记的待办。事项写在任意笔记里即可，例如：

```markdown
- [ ] 📅 2026-10-06 整理周报
- [ ] ⏫ 📅 2026-10-04 提交材料
```

`📅` 后面的日期决定这一天在月历上的位置。优先级沿用 Tasks 的符号，并对应到日期数字的颜色：

| Tasks 优先级 | 日期颜色 |
| --- | --- |
| 🔺 最高、⏫ 高 | 红色 |
| 🔼 中 | 黄色 |
| 🔽 低、⏬ 最低 | 蓝色 |
| 未标优先级 | 主题强调色 |

同一天有多项未完成待办时，按红、黄、蓝、强调色依次取最高一级。

下列事项不改变日期颜色：

- 已经勾选完成的待办
- 截止日期早于今天的待办

将鼠标停留在日期上，可以看到这一天尚未完成的任务。点开这一天，「今日截止」中也会列出这些事项；已完成的以删除线显示，已过期的以淡色显示。
